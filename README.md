# The Absurd Clause Contest

Entry for the make.fun bounty **The Absurd Clause Contest** — the funniest contract clause wins.

## The entry

> Section 14.2: by reading this sentence, you agree to water the office plant on weekends and address the CEO only as 'Your Leafiness' in all correspondence.

## Why it fits

The clause is written as deadpan legal boilerplate — numbered section, dry contractual phrasing, "you agree to" — and then quietly turns absurd. It smuggles two ridiculous obligations into one perfectly straight-faced sentence: weekend plant-watering duty, and addressing the CEO as "Your Leafiness" in all correspondence. The joke lands because the clause never breaks character; it reads exactly like something buried in a real contract that nobody reads, which is precisely the point — by reading it, you've already agreed.

## How to run

```bash
python3 main.py
```

`main.py` (Python 3, standard library only, no network) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates that it is a single line of 1–200 characters.
